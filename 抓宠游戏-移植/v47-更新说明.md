## 一、伤害公式：换成官方主体

### 改前的公式（三个问题）

```
伤害 = 威力 × 克制 × lvBonus × lvPress × (clamp(A/D, 0.9, 1.6) × 0.26) × 性格攻 / 性格防
```

| 问题 | 说明 |
|---|---|
| **lvBonus**（自创） | `0.55 + 0.055×(Lv−1)` 的「等级伤害折算」，再加上 1~13 级的额外折算 |
| **lvPress**（自创，还被乘了两次） | `0.5 + 0.5×(攻方等级 ÷ 守方等级)` —— v46 之前 atkM 与 base 各乘一次，等于**平方** |
| **攻防比被钳制** | `clamp(A/D, 0.9, 1.6)` 把「面板强 3 倍」和「面板强 8 倍」压成同一档 —— 练级和挑种族的优势体现不出来 |

你那场 Lv5 打 Lv7 就是这三条一起作用：`0.857²=0.735` vs `1.2²=1.44`（1.96 倍）＋性格 1.36 倍＋其它，最终放大成 4 点 vs 20 点。

### 现在的公式（官方主体）

```
核心 = floor( floor( (2×Lv/5 + 2) × 威力 × A/D ) / 50 ) + 2      ← 宝可梦官方（第三世代起）
伤害 = 核心 × DMG_K × 克制 × 性格攻/防 × 能力等级 × 连击 × 随机 × 暴击
```

- **删掉了** `lvBonus`、`lvPress`、攻防比的 0.9~1.6 钳制
- **A/D 用真实面板值**（物理招读 攻/防，特殊招读 特攻/特防）
- 等级现在**只通过两条官方途径**影响伤害：① 能力值本身随等级增长（就是面板）② 官方等级项 `(2×Lv/5+2)`
- 全局系数 `DMG_K` 从 0.26 重新标定为 **1.2**（目标：同级 3~5 回合）

### `DMG_K` 到底是什么（实测扫描）

它是伤害公式最后**统一乘的一个倍率**，作用等于「整体音量旋钮」：只决定伤害整体快慢，
**不改变任何相对关系**（面板差、属性克制、性格、等级差、暴击全都不动）。

```

0.6   | 11.3% / 8.9 回合    | 11.1% / 9.0 回合    | 3.3 / 5.6 = 1.70 倍          | 2.6%
0.8   | 15.2% / 6.6 回合    | 15.0% / 6.7 回合    | 4.4 / 7.3 = 1.65 倍          | 3.4%
1.0   | 19.3% / 5.2 回合    | 18.7% / 5.4 回合    | 5.4 / 9.2 = 1.70 倍          | 4.3%
1.2 ← | 22.9% / 4.4 回合    | 22.6% / 4.4 回合    | 6.5 / 10.8 = 1.68 倍         | 5.1%
1.5   | 28.1% / 3.6 回合    | 28.7% / 3.5 回合    | 8.1 / 13.7 = 1.69 倍         | 6.3%
```

这正是「只缩放整体、不动相对关系」的证据。想调战斗节奏就改它一个数，其它结论都不受影响。
（历史：v26 时它是 0.26，因为当时公式里有 lvBonus 提供的 ~3.2 倍放大；v47 换公式后重新标定为 1.2。）

## 六、本批新增的坑

58. **「钳制」会让上游的改动全部失效**：`clamp(A/D, 0.9, 1.6)` 本意是防止极端伤害，但它同时把「练级收益」「种族差异」「等级压制」全部压平 —— 玩家看到的数字差异，八成来自钳制之后的系数（等级、性格），而不是面板。**教训**：给比值加钳制前想清楚它会不会掩盖你想让玩家感知的那个变量；本次去掉钳制后，「面板说话」才真正成立。
59. **两个自创系数叠加时，很难判断是哪个在起作用**：`lvBonus`（随等级增长）与 `lvPress`（等级差压制）方向相同、都在放大等级的作用，所以「低等级打高等级特别难」既可能是前者也可能是后者 —— 直到把两者都拆掉，才看清原来 `lvPress` 还被乘了两次。**教训**：同一维度上不要叠两个自创系数；真要叠，至少让它们的作用可分别关闭以便对照测试。
60. **CSS flex 里「标签 + 长内容」会压扁标签**：`justify-content:space-between` 的容器中，内容一长，左侧标签会被挤到逐字换行（「性」「格」竖排）。**教训**：标签给 `white-space:nowrap; flex:0 0 auto`，让内容去换行 —— 这个坑在 v43 的「捕获率」行也踩过一次，是同一个根因。
