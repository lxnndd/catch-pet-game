## 一、神兽占比统计 → 刷新权重已下调

**统计结果**：

| 档位 | 数量 | 占总宠物数 |
|---|---|---|
| 普通 | 1100 | 91.29% |
| 传说 / 幻之 | **105** | **8.71%** |
| 合计 | 1205 | 100% |

而三档刷新权重是 `[1, 1, 1]`（v43 的"平权"）——
所以**每遇到约 11 只，就有 1 只是神兽（8.71%）**，初期满地神兽。

**反推权重**（以普通档 = 1 为基准）：

| 想让神兽占比 | `RARITY_W[2]` 应设为 |
|---|---|
| 1% | 0.106 |
| **0.5%（本次采用）** | **0.053 → 取 0.05** |
| 0.2% | 0.021 |
| 0.1% | 0.0105 |

**改动**：`var RARITY_W=[1,1,0.05];`

**实测**（6000 次遇敌）：
```
理论神兽占比 0.48% · 实测 33 只 / 6000 次 = **0.55%**   ✅
（对比修复前：8.71% → 现在约 200 次遇敌才出 1 只神兽）
神兽仍然会遇到，只是很稀有 —— 不再是"满地图"
```

## 二、变身（百变怪）—— 原来是完全无效

百变怪只有一个技能「变身」，而 `MOVE_FX` 里没有它的条目 → **放了完全没反应**。

**按官方实现**（变成对手的样子，复制其物种与招式）：

```js
/* v93：变身 —— 本作的属性与种族值都由「物种 id」决定，所以变身 = 临时换上对手的物种 */
if(fx.transform){
  var _tgSp=(atkF===selfPet())?B.esp:leadSp();
  if(!vsGet(_me,"origSp")) vsSet(_me,"origSp",_me.sp);   // 记住原形
  _me.sp=_tgSp.id;                                       // 物种（属性/种族值）
  _me.moves=_tgSp.moves.slice(0,SKILL_SLOTS);            // 招式
  STAGE_KEYS.forEach(k => _me.st[k]=defF.st[k]||0);      // 能力变化一并复制
  ...立绘与名字同步...
}
```

**原形还原**：`clearStatus()`（换场 / 战斗结束）里把 `sp` 换回去。

**实测**：
```
变身日志：🎭 百变怪 变身成了 喷火龙！
物种：百变怪 → **喷火龙** → 换场还原为 百变怪        ✅
招式：变身 → 空气之刃 / 抓 / 叫声 / 火花（复制对手）  ✅
```

## 六、本批新增的坑

102. **统计口径会决定结论**：我第一遍把"`fxOf` 返回空"当成"技能没效果"，得出"洛克 232 条无效"的吓人数字；
   按 `cat` 分开统计后才发现——**攻击招本来就没有附加效果**，真正缺的只有 4 条。
   **教训**：出统计前先想清楚"这个类别里，什么算正常"，否则会把正常数据当成缺陷报上去。
103. **"平权"是个会过期的设定**：v43 按你的要求把三档刷新权重都设成 1（当时是为了修"稀有的几乎遇不到"），
   但神兽占 8.71% 的基数下，等概率就等于"神兽满地跑"。**教训**：权重这类参数要跟**基数占比**一起看，
   单独一个 `[1,1,1]` 在不同数量分布下含义完全不同。
