## 一、改动

大会每场之后的恢复，现在是 **付费服务**：

| 项目 | v90 | v91（本次） |
|---|---|---|
| 恢复范围 | 只恢复 `HP>0` 的伙伴 | **倒下的伙伴也一并救活** |
| 费用 | 免费 | **要花钱**（每只 `等级 × 3` 金币） |
| 金币不足 | —— | **不恢复**，提示一句，残血继续打下一场 |

```js
/* v91：联盟大会每打完一场的恢复服务（要花钱） */
function arenaHealCost(){                       /* 费用 = Σ(每只等级 × 3) */
  var c=0; S.party.forEach(function(p){ c += Math.max(1,p.lv||1)*3; });
  return c;
}
function arenaHeal(){
  var cost=arenaHealCost();
  if((S.coins||0) < cost){ toast("💰 金币不足：…残血继续打！"); return 0; }
  S.coins -= cost;
  var revived=0;
  S.party.forEach(function(p){
    if(p.hp<=0) revived++;                      /* 倒下的也救活 */
    p.hp = maxHpOf(p);
    ensureMoves(p);
    p.moves.forEach(function(id){ p.pp[id] = ppMaxOf(id); });   /* PP 回满 */
  });
  refreshHP(); updateHUD(); save();
  toast("💊 花掉 🪙"+cost+" 恢复全队 HP/PP" + (revived ? ("，救活了 "+revived+" 只倒下的伙伴") : ""));
}
```

联盟面板说明也改了：

```
· 每打完一场会**花费金币**恢复全队 HP/PP（倒下的伙伴也会被救活）；金币不够则不恢复
· 单败淘汰：输一场就要从 128 强重新打起
· 连胜 7 轮拿下大会优胜，才有资格挑战四天王
```

## 三、费用设计

- **公式**：每只伙伴 `等级 × 3` 金币 → 全队求和
- **例**：主力 Lv60 + 替补 Lv30 = (60+30)×3 = **270 金币**
- **含倒下的**：倒下的伙伴也按等级计费（毕竟要救活它）
- **打不过就攒钱**：金币不足时不会恢复 —— 这时要么硬打，要么先去刷钱

## 四、可调旋钮

| 想改什么 | 位置 | 现值 |
|---|---|---|
| 单价系数 | `arenaHealCost()` 的 `*3` | 等级 × 3 |

| 金币不足时 | `arenaHeal()` 的 `return 0` | 完全不恢复 |

## 六、本批新增的坑

101. **测试的"基准值"要在被测操作之前、且在其它赋值之后取**：我把 `coinsBefore` 记在
   `S.coins = 99999` **之前**，于是"扣款金额"的比对基准是初始金币，怎么算都不等。
   **教训**：凡是"变化量"断言，基准值必须紧贴被测操作前一行取，中间不要插入其它写操作。
