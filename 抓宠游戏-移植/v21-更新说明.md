## 一、你报的三点

### ① 「背景板不是纯色，比如花海的道馆所在的背景都是花」
原来城镇地面是**单色块**（按道馆属性刷一个色）。现在改成**该地区的标志地形图案**，不再纯色：

| 城镇 | 地面地形（真实格子数） | 看起来像 |
|---|---|---|
| 花海镇 | **花田 106 格** + 高草 19 | 整片粉紫花田（还加了底色，一眼就是花海） |
| 林间镇 | 草地 97 + **树 72** | 林间草地 |
| 矿洞镇 | **岩地 117** + 岩壁 8 | 灰岩矿洞地面 |
| 平原镇 | 草地 116 + 花 9 | 草地小镇 |
| 荒漠镇 | 沙地 + 零星高草 | 沙土镇 |
| 雪原镇 | 雪地（白）+ 少量冰丘 | 雪原小镇 |
| 火山镇 | 暗岩地 + 少量岩浆 | 火山岩地 |
| 海洋镇 | 沙滩 + 少量水洼 | 海滨小镇 |

**顺带**：花田原来只画零星花点、底还是绿色，现在**铺了花田底色**（粉紫）+ 8 个花点，所以截图里整片就是花。

### ② 「林间和花海的道馆怎么重叠了」
实测把 8 座城镇**两两距离**全量算了一遍，重叠的不是林间/花海，而是 **荒漠镇 ↔ 雪原镇**：
> 荒漠镇 @174,40 与 雪原镇 @174,28 —— 纵向只差 **12 格**，而城镇区域高 **13 格** → 两个城镇压在一起了

已修：选址时增加**最小间距校验**（`|Δx| < 26 或 |Δy| < 20` 就不允许），现在 8 座城镇的 17×13 区域**两两都不相交**（最近的一对也已横向错开 26 格）。

### ③ 「中心城镇的大道颜色和荒漠重复了，把颜色变一变」
原来城镇街道用的是 `T.PATH`（沙色 `#dcc99b`），而**荒漠地区的地面也是沙色**，所以撞色。
新增**石板街道地形 `T.STREET`**（石板灰 `#b9b3a7` + 石板纹理），城镇的十字街和四向通道都改用它 —— 现在**灰色石板街 vs 黄色沙地**一眼能分辨。
