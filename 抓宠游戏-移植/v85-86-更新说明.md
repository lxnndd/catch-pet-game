# 抓宠游戏 v85~v86 更新说明 —— 神兽野生个体一律 70 级起

> 线上地址：**http://47.105.123.182:8727/**
> 你的要求：「神兽初始等级直接 70+，降低初期抓到的可能性」

---

## 一、改了什么

`wildLvRange()`（决定野生个体等级的入口）里加了一条：

```js
/* v85 神兽等级：传说 / 幻之（稀有度 2）的野生个体一律 70 级起 */
if(sp && sp.rarity===2) return [70,100];
```

**关键点**：神兽的等级**不再受**两件事影响 ——
- ❌ 地区的等级段（平原本来只到 25 级）
- ❌ 玩家的等级（v53 起野怪跟随出战宠 ±3）

## 二、为什么原来初期能抓到

v53 把野怪等级改成「跟随当前出战宠 ±3」后，**神兽也一起跟随** ——
所以 5 级玩家在平原就能撞见 **2~8 级的神兽**，一发精灵球就带走了。

## 三、实测（`v86-legend.mjs`，7/7）

**区间随玩家等级的变化**：

| 玩家最高等级 | 神兽区间 | 普通宠区间 |
|---|---|---|
| Lv1 | **[70,100]** | [1,4] |
| Lv5 | **[70,100]** | [2,8] |
| Lv10 | **[70,100]** | [7,13] |
| Lv30 | **[70,100]** | [1,15]（改用地区段） |
| Lv60 | **[70,100]** | [1,15] |

**实战抽样（Lv5 玩家，4000 次遇敌）**：
```
神兽：出现 577 次，等级 70~100      ← 全部 70 级以上
普通/稀有：出现 3423 次，等级 2~8   ← 完全不受影响
```

**Lv90 玩家**：神兽仍是 `[70,100]`（不会被抬到 90+），实测 278 次出现均为 70~100 ✅

## 四、效果

- 初期遇到神兽 → **70 级起步**，打不过也抓不动（捕捉率本来就低：传说多为 3，满血精灵球约 1.6%）
- 想抓神兽 → 得先把队伍练到 **70 级附近**，有了对等的战力才有机会
- **神兽仍然会正常刷新**（没有被过滤掉，只是等级高了）

## 七、本批新增的坑

95. **改动会"逆向"影响老测试的假设**：神兽改成 70 级后，`v51` 里"所有野怪等级都在自己的进化阶段区间内 / 新手期都是 ±3"
   这几条**必然失败**（神兽本来就是例外）。测试不是坏了，是**前提变了**。**教训**：给某类数据开特例时，
   要同步检查此前写的"全体断言"是否需要把特例排除。
96. **带命中率的招式不能只测一次**：`v80` 的音爆（命中 90）和 `v76` 的打雷（命中 70）都出现过
   "偶尔失败" —— 不是机制错，是**一次采样撞上了那 10%/30% 的打空**。**教训**：验收里凡涉及
   "命中/概率"的断言，要么多次采样，要么用必中的招式做基准，否则会产出**随机失败的测试**（很消耗排查时间）。
