# v18 施工方案：地图放大 9 倍 + 环形难度重排 + 地区等级制

> 用户定稿（2026-09-23）：
> 1. 九地区按等级段：平原/林间/水畔 **1-25** → 花海 **26-35** → 矿洞 **36-45** → 荒漠 **46-55** → 海洋 **56-65** → 火山/雪原 **66-75**
> 2. 地图 **216×156**（长宽各×3，面积 9 倍）
> 3. 野怪等级 = **地区区间 + 跟着玩家最强宠浮动**
> 4. 地区按难度**由中心向外环形**排开
> 5. 顺带修：矿洞开路、雪原换造型（不再用岩石当冰丘）

---

## 一、地图尺寸与性能（关键约束）

| 项 | 现在 | v18 |
|---|---|---|
| 格子数 | 72×52 = 3,744 | **216×156 = 33,696（9 倍）** |
| 存档 mapStr | 3,744 字符 | 33,696 字符（localStorage 无压力，约 34KB） |
| 每帧绘制 | 全图 3,744 格遍历 | **必须改成只画视口内**（否则 9 倍开销） |
| 视野 | 约 30×20 格 | 保持 30×20（格子更大、看得更远 = 更开阔）或略放大到 36×24 |

**必做**：`draw()` 里把「全图遍历」改成「只遍历视口矩形」。
**必做**：`resizeCanvas` 的 TILE 尺寸随屏幕自适应，保证一屏约 30×20 格。

## 二、九地区环形布局（从中心向外，难度递增）

地图中心 `C = (108, 78)`。出生点与医院放中心附近。

用「切比雪夫环」（`d = max(|dx|, |dy|)`）分层，最外圈按方位切分成山头：

| 环 | 距离带 | 地区 | 等级段 | 说明 |
|---|---|---|---|---|
| 0 | d ≤ 14 | **平原** | 1-25 | 出生点 + 医院，新手安全区 |
| 1 | 14 < d ≤ 30 | **花海** | 26-35 | 第一道风景环 |
| 2 | 30 < d ≤ 44 | **矿洞** | 36-45 | 中层矿山带 |
| 3 | 44 < d ≤ 58 | **荒漠** | 46-55 | 沙化环 |
| 4-5 | d > 58 | **海洋 / 火山 / 雪原** | 56-75 | 最外圈按方位分：**东侧+南侧=海洋**（海岸线）、**西侧+西南=火山**、**北侧+东北=雪原** |

- 林间与水畔不再单独占环，而是**作为地形特征散布在平原/花海环内**（树≥9→林间、水≥3→水畔），这样它们保持 1-25 段。
- 这样「出生点在最中间，越往外越硬」，与用户要的环形推进完全一致。

## 三、地形生成重写（genMap）

现有 14 处写死的 `patch()` / `ring()` 坐标全部作废，改为**按环批量生成**：

- **平原环**：中心广场 + 十字主干道（医院在路口，保留用户看到的十字，但把医院挪到广场旁而不是路口正中，避免"医院被十字穿过"的观感）+ 散布高草丛
- **花海环**：一圈花田（`ring` 大半径），花丛密度高于现在，形成明显"花海"带
- **矿洞环**：**必须留出可通行入口**（从主路辐射出 4~8 条 `PATH` 走廊贯穿矿洞环），岩壁覆盖率从 82% 降到约 55%，保证可达率 > 70%
- **荒漠环**：沙路 + 稀疏仙人掌（用 `TALL` 占位）
- **海洋环**（东/南）：`DEEP` 核心 + `WATER` 浅滩外环 + 沙滩过渡带
- **火山环**（西/西南）：岩浆池 + 黑岩 + 必须留通道
- **雪原环**（北/东北）：**新增雪地地形**（用现有的 `FLOWER` 槽位改造为 `SNOW` 或新增 `T.SNOW=10`），白色雪原视觉，**不再用岩石**
- 边界 1 圈树墙（防出界），保留

**可达性硬指标**：改造后写脚本验证——**九地区可达率全部 > 70%**（现在矿洞仅 37%）。

## 四、地区判定重写（regionAt）

从「写死坐标」改为「环形 + 方位」：

```
function regionAt(x,y){
  var d = max(|x-CX|, |y-CY|);
  if(d <= 14) return "plain";
  if(d <= 30) return "flower";     // 内部再按树/水特征细分出 forest / water
  if(d <= 44) return "mine";
  if(d <= 58) return "desert";
  // 最外圈按方位
  var ang = atan2(y-CY, x-CX);
  if(东/南向) return "ocean";
  if(西/西南向) return "volcano";
  return "snow";
}
```
- 环内仍保留邻域特征判定（树≥9→林间、水≥3→水畔），让林间/水畔出现在 1-25 段。
- **约束**：最外圈火山与海洋要隔开（不能相邻），沿用 v13 的设计约束。

## 五、等级制（用户选：地区区间 + 跟玩家浮动）

```
地区等级区间 LV_RANGE = { plain:[1,25], forest:[1,25], water:[1,25], flower:[26,35],
                          mine:[36,45], desert:[46,55], ocean:[56,65], volcano:[66,75], snow:[66,75] }

野怪等级 = clamp( 玩家最强宠等级 ± 3 , 区间下限 , 区间上限 )
```
- 效果：1 级新手在平原只会遇到 1~4 级；练到 60 级回平原会遇到 23~25 级；去火山则至少 66 级。
- 保留现有的「低等级野怪不许用大招」威力上限表（它防止新手被高威力招秒杀）。
- **训练师等级**同步改为按所在地区的区间取（而不是纯跟玩家），让远处训练师真的更强。
- UI：`hint` 里显示当前地区的等级段，例如「当前花海 · 建议 Lv.26~35」。

## 六、顺带修复清单

1. **矿洞开路**：辐射式 `PATH` 走廊 + 降低岩壁覆盖率 → 可达率 > 70%
2. **雪原造型**：新增雪地地形（白色），与岩石区分；雪原环内岩石只作为少量点缀
3. **医院十字**：医院从路口正中挪到广场一侧，主干道仍保留（走图方便）
4. **视野自适应**：一屏保持约 30×20 格，地图变大后不至于"看不见路"
5. **draw() 视口裁剪**：只画可见格子，保证 9 倍地图不掉帧
