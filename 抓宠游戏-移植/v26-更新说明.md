## 三、战斗平衡（重点，已重做定标）

**你报的现象**：20 级火恐龙用喷射火焰打 56 级巨牙鲨，扣 93 HP，而对方总共 128 HP。

**实测复现**（真实战斗流程，非估算）：正常 51 / 暴击 82~94，对方 156 血 → 33% / 52%，与你看到的完全对得上。

**但顺着一查，发现更深的问题**：

> 全等级段同级对战只有 **约 1.2 回合** —— 伤害几乎全部顶到「单次伤害上限 = 目标血上限 85%」，也就是**同级互殴两击必杀**。之前标定的「3~4 回合」节奏已经失效了。

**根因**：伤害公式的整体量级约为宝可梦官方公式的 **5 倍**（全局系数 0.75 是硬编码在 `statMul` 里的）；而且等级只影响攻击方（`lvBonus` 只看攻方等级），**没有等级差的概念**。

**改动（3 处 + 1 处新增）**：

| 项 | 旧 | 新 | 目的 |
|---|---|---|---|
| 全局伤害系数 | `×0.75` 硬编码 | `DMG_K=0.26`（抽出为常量） | 把量级拉回宝可梦水平，同级回到 3~4 回合 |
| **等级压制** | 无 | 新增 `lvPress = clamp(0.5 + 0.5×(攻方等级/守方等级), 0.5, 2.0)` | 同级 = 1（不动既有节奏），越级明显压制 |
| 等级加成上限 | 3.2（56 级就封顶） | 4.2 | 高等级不再「血量涨、伤害不涨」 |
| 开局折算 | 0.55 起 | 0.75 起 | 1 级不再拖到 7.8 回合 |

**改后实测**：

| 场景 | 改前 | 改后 |
|---|---|---|
| **你报的那场**（20 火恐龙喷火 → 56 巨牙鲨） | 93/128 = **73%** | 7/156 = **4%** |
| 20 级同级对战 | 1.18 回合（85%） | **2.4~2.9 回合**（35~42%） |
| 56 级同级对战 | 1.17 回合（85%） | **2.4~2.7 回合**（38~42%） |
| 56 级打 20 级 | 85% | 74~85%（仍是碾压） |
| 等级压制比 | 1×（无压制） | **7~10×** |

全等级段扫描（Lv1/5/10/20/30/40/50/60/80/100）同级回合数：**4.6 / 5.3 / 3.4 / 2.8 / 3.4 / 3.1 / 3.1 / 3.8 / 3.7 / 4.5**，均值约 3.8 回合。

**两个旋钮**（想再调手感直接改这两个）：

- `DMG_K`（现 0.26）：调大 → 整体节奏更快；
- `lvPress` 里的 `0.5 + 0.5×比值`（现范围 0.5~2.0）：想让等级差更狠就提高系数、放宽 clamp。

回归命令：`cd _work\tools && node v26-balance-sweep.mjs`（各等级段回合数）、`node v26-real-battle.mjs`（真实战斗数值）。
