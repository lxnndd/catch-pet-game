## 一、改动

上一版只回 HP（PP 不回），现在改为**HP 与 PP 全回满**：

```js
/* v90：联盟大会每打完一场，全队存活伙伴 HP 与 PP 全回满 */
function arenaHeal(){
  var n=0;
  S.party.forEach(function(p){
    if(p.hp>0){
      p.hp = maxHpOf(p);
      ensureMoves(p);
      p.pp = p.pp || {};
      p.moves.forEach(function(id){ if(MOVES[id]) p.pp[id] = ppMaxOf(id); });   /* PP 按技能表重建为满 */
      n++;
    }
  });
  refreshHP(); save();
  return n;
}
```

文案同步更新：

| 位置 | 改前 | 改后 |
|---|---|---|
| 联盟面板 | 每打完一场，全队 HP 会回满（PP 不回），越往后对手越强 | 每打完一场，全队 **HP 与 PP 全回满**，越往后对手越强 |
| 晋级提示 | 🎪 晋级 XX！全队 HP 已回满（PP 不回）… | 🎪 晋级 XX！全队 **HP / PP 已回满**… |
