## 二、本轮实现的 6 项机制（实测数据）

### ① 掉包 / 戏法 —— 封闭使用但保留占位

官方是「与对手交换持有道具」，本作**没有道具系统**。按你的要求：招式**留在表里占位**，
使用时直接拦下并说明原因：

```
掉包：可用=false
提示「官方是与对手交换持有道具，本作没有道具系统（招式已占位保留）」
出招日志：⛔ 掉包 暂未开放：官方是与对手交换持有道具…
```
按钮也会置灰（`moveAllowed` 返回 false）。等以后加了道具系统，把 `blocked` 标记删掉即可启用。

### ② 地狱突刺 —— 2 回合内禁用声音类招式

官方数据里它的 `ailment = silence`（2 回合）✅ 已按官方实现：

```
声音招「叫声」：沉默前可用 ✅ → 沉默后**不可用**，提示「被地狱突刺封住了声音，无法使用这类招式！」
普通招「撞击」：沉默前后都可用（不受影响）✅
```

### ③ 空中状态 + 击落

- 使用 **飞翔 / 弹跳 / 自由落体** 时，使用者进入**空中状态**（日志「🕊 飞上了天空……（下回合发动 飞翔）」）
- 空中时，**只有官方清单里的招式能打中**：高速星星 · 起风 · 打雷 · 吹飞 · 龙卷风 · 冲天拳 · **击落** · 暴风 · 音爆 · 千箭齐发 · 剧毒
- 其余招式一律落空 → 实测「💨 喷火龙 飞在空中，撞击 打不中它！」（伤害 0）
- **击落**：能打中空中目标（实测 31 点伤害）→ **解除空中状态** → 并且**打断正在蓄力的招式**

> 注：「千箭齐发」「冰球」本作的招式映射表里没有收录，机制已备好、待收录即生效。

### ④ 意念移物

3 回合内目标浮在空中、**我方招式必中**（实测命中率 100%）。
按官方说明，此招在「重力」下无法使用 —— 本作没有重力场，故未限制；
对超级耿鬼/地鼠等无效的规则依赖具体形态，本作也没有超级进化，同样未做限制。

### ⑤ 三重攻击

## 五、本批新增的坑

87. **"官方数据里有的字段"也要先验证非空**：我以为 PokéAPI 会给声音招打 `sound` flag，直接写好了筛法，
   跑出来 **0 条**才发现它根本没建这个分类。**教训**：跨数据源取字段前，先用一条**已知应该命中**的记录验证
   （比如拿"叫声"试），别等全量跑完才发现字段是空的。
88. **同一份数据里"实现得了"和"实现不了"要分开标注**：掉包与其半吊子地给个降攻击效果，
   不如**明确封闭并写清原因**（用户也是这么要求的）。**教训**：依赖缺失系统的机制，**
   占位 + 明确说明**比"编个近似效果"更诚实、也更好维护（以后补上系统时只要删一个标记）。
89. **在错误的函数里引用变量**：我把「掉包封闭」的日志写进了 `applyVolatile()`，而那里没有 `mv`
   —— 又一次同类错误（v75 是 `selfP`）。**教训**：抽出来的子函数要明确"它能拿到什么"，
   日志需要的上下文（招式名等）应该在**调用方**拼好再传进去。
