## 一、野外刷新概率：三档拉平

| | 改前 | 改后 |
|---|---|---|
| 加权（常见 : 稀有 : 传说） | `1 : 0.087 : 0.0011` | **`1 : 1 : 1`** |
| 低等级稀有度限制 | 8 级以下只出常见、15 级以下不出传说 | **已取消** |

稀有度现在**只**用于两件事：标签配色、以及（间接的）捕获率 —— 不再影响谁会出现。

**实测**（玩家 Lv1，平原地区池 150 只、其中传说档 16 只，抽样 1200 次）：

```
普通 973 · 稀有 98 · 传说 129        传说档期望 = 16/150 × 1200 = 128.0  ✅
```

也就是说神兽和常见宠**一样容易遇到**了（出现比例 = 池内数量比例），而 1 级玩家也能遇到传说档。

## 二、捕获率：改用宝可梦官方公式

### 你问的「神兽满血 0.4%」——查证结果

| | 数值 | 说明 |
|---|---|---|
| **你记的** | 0.4% | — |
| **我们改前的公式** | **4.5%** | `(10% + 掉血×75%) × 球倍率 × DIFF[稀有度]`，满血神兽 DIFF=0.45、标准球 1.0 → 0.10×0.45 |
| **官方** | **1.57%** | 捕获率 3 的神兽，满血 · 精灵球 · 无状态 |

（三个数都不一样，所以这次干脆**直接照官方实现**，不再用自研系数。）

### 官方公式（第三/四世代起，[52poke·捕获率](https://wiki.52poke.com/zh-hans/%E6%8D%95%E8%8E%B7%E7%8E%87)）

```
a = ((3×maxHP − 2×当前HP) × 捕获率 × 球倍率) / (3×maxHP) × 状态加成
a ≥ 255 → 必定捕获
否则 b = 65536 / (255/a)^0.1875 ，摇 4 次全部通过才算捕获成功
```

### 官方数值表（本作实测，满血 · 无状态）

| 捕获率 | 标准球 1× | 加强球 1.5× | 精英球 2× | 谁是这个档 |
|---|---|---|---|---|
| **3** | **1.57%** | 2.12% | 2.64% | 76 只（传说/幻兽：超梦、洛奇亚、凤王…） |
| 5 | 2.30% | 3.12% | 3.87% | 3 只 |
| 10 | 3.87% | 5.24% | 6.50% | 11 只 |
| 25 | 7.69% | 10.42% | 12.93% | 19 只 |
| **45** | **11.94%** | 16.19% | 20.09% | 313 只（御三家等最常见档） |
| 90 | 20.09% | 27.23% | 33.78% | 49 只 |
| 190 | 35.18% | 47.69% | 59.17% | 92 只（皮卡丘就是这档） |
| 255 | 43.87% | 59.46% | 73.78% | 87 只（最易抓） |

**血量项也在**（以捕获率 3 为例）：满血 1.57% → 半血 2.64% → 1/3 血 2.95% → 残血 3.55%
**状态加成**：睡眠 / 冰冻 **×2.5** · 麻痹 / 中毒 / 灼烧 **×1.5**（→ 睡眠状态下神兽 3.12%）

### 官方是怎么分「神兽 / 异兽」的

官方**没有**「稀有度档位」这个用于捕获的字段 —— 每只宝可梦只有一个 1~255 的**捕获率**：

- **传说 / 幻之**：普遍是 **3**（本作图鉴里 76 只）；个别例外（如烈空坐官方是 45）
- **究极异兽**：捕获率也是 45，但官方的特殊之处在**球**上 —— 究极球对它们 5×、其它所有球强制 0.1×（本作没有究极球，所以异兽目前与普通宠同档）
- **普通**：45 是出现最多的档；255 是最好抓的（虫系、小拉达这类）

数据来源就是我们已有的 PokéAPI 缓存（`capture_rate` 字段），**1025 只全部注入**。
洛克王国官方没有这个概念 → 按稀有度给基准（普通 120 / 稀有 75 / 传说 25）。

### 球倍率也改成官方

| 球 | 改前 | 改后（官方） |
|---|---|---|
| 标准球 | 1.0× | **1×**（精灵球） |
| 加强球 | 1.4× | **1.5×**（超级球） |
| 精英球 | 1.8× | **2×**（高级球） |

## 八、本批新增的坑

50. **用户报的数值要先复算，别照着改**：你提到「神兽满血抓取概率 0.4%」，实际复算是 —— 改前的自研公式给的是 **4.5%**，而官方是 **1.57%**，三个数都不一样。**教训**：用户给的数字可能来自记忆或别处，先把自己的公式复算一遍、再和官方对账，然后照**官方**实现，而不是往用户说的数字上调。
51. **改配色必须检查浅色底的可读性**：官方属性色里电 `#f7d02c`、冰 `#96d9d6`、地面 `#e2bf65`、钢 `#b7b7ce` 都很浅，原来的标签是「白字 + 深底」，直接套上去白字看不见。**教训**：换配色时要连同**文字颜色**一起按底色明暗决定。
52. **取消「保护性过滤」前要评估副作用**：低等级不出传说是 v15 特意加的新手保护。这次按需求取消后，1 级玩家也会遇到神兽 —— 之所以安全，是因为本作野怪等级由地区决定（神兽不额外强），且捕获率按官方（1.57%，抓不到也不至于破坏体验）。**教训**：删保护逻辑时把「它当初防的是什么」写清楚，再判断现在还需要不需要。
53. **在模板字符串里写正则，`\b` 会被提前吃掉**：验收脚本是用模板字符串把 JS 代码注入浏览器的，我在里面写了 `/\bon\b/.test(cls)` —— 模板字符串在 Node 端就已经把 `\b` 转义成**退格符 `\x08`**，浏览器实际执行的是 `/退格on退格/`，断言必然失败；而打印出来的 className 明明是 `"btn-sm on"`，看起来像游戏坏了。**教训**：往浏览器注入代码时，正则里的 `\b \d \s` 这类转义要写双反斜杠，或者干脆绕开正则（本次改成 `className.split(' ').indexOf('on')>=0`）。
