## 一、删掉「编造的效果」

### 1. 属性兜底不再用于宝可梦招式

原来 `fxOf()` 对**所有**变化技有个兜底：`FX_BY_TYPE[属性] || {buff:{def:1}}` ——
于是「挑衅」（恶系）显示成「**对手 防御 -1**」，而官方机制是「3 回合内只能使出攻击招式」。

现在：**宝可梦招式以官方为准**，官方没有可实现的附加效果 → `fxOf` 返回 `null`，
提示框如实显示「暂无附加效果」；属性兜底**只对洛克招式保留**（它们本来就没有官方数据）。

### 2. 提示框文案

`本作效果：` → **`游戏内效果：`**，并区分三种情况：

```
挑衅      → 对手 防御 -1（官方机制本作未实现，这里按「恶系变化技」的兜底效果处理）   ← 旧
挑衅      → 😤 对手被挑衅了（3 回合内只能使用攻击招式）！                            ← 现在（真机制）
守住      → 自身 防御 +1（官方为「完全挡下对手本回合的攻击」，本作以这个效果近似）      ← 旧
守住      → 🛡 撑起保护罩（完全免伤）                                                ← 现在（真机制）
```

## 三、三处数据错误（你的反馈挖出来的）

### ① 增强拳方向标反了 —— 一共 16 条招全反

PokéAPI 把「攻击后**自己**能力变化」的招（`category = damage-raise`）的 `target` 一律标成 `selected-pokemon`，
而生成脚本只按 `target` 判方向，于是：

| 招式 | 官方 | 修复前 | 修复后 |
|---|---|---|---|
| **增强拳** | 自己攻击 +1 | **对手 攻击 −1** ❌ | 自己攻击 +1 ✅ |
| 近身战 | 自己防御/特防 −1 | 对手 防御/特防 +1 | 自己降 ✅ |
| 臂锤 | 自己速度 −1 | 对手 速度 +1 | ✅ |
| 蛮力 | 自己攻击/防御 −1 | 对手 攻击/防御 +1 | ✅ |
| 飞叶风暴 / 过热 | 自己特攻 −2 | 对手 特攻 +2 | ✅ |
| 金属爪 / 彗星拳 | 自己攻击 +1 | 对手 攻击 −1 | ✅ |
| 钢翼 | 自己防御 +1 | 对手 防御 −1 | ✅ |
| 原始之力 / 奇异之风 / 银色旋风 | 自己全能力 +1 | 对手 全能力 −1 | ✅ |
| 充电光束 / 蓄能焰袭 / 高速旋转 / 耕地 | 自己能力 +1 | 对手 −1 | ✅ |

**修法**：方向改用 `meta.category` 判定（`damage-raise`→自己、`damage-lower`→对手），`target` 只作最后兜底。

### ② 乱抓这类连击招**从来没连击过**

本作 `MOVES` 里**一直没有 `hits` 字段**（v17 声称注入了，实际没落到数据里），
所以 19 条连击招全部只打一下；而且代码里还挂着一个**自创的 0.62 伤害倍率**（从未生效）。

**修法**：连击次数从官方 `meta.min_hits/max_hits` 读（官方优先），去掉 0.62 倍率
（官方连击**每次按完整威力**结算，平衡靠"单次威力低"——乱抓威力只有 18）。
实测：200 次乱抓 → 2/3/4/5 次分布正常 ✅

## 六、本批新增的坑

74. **数据源的「语义字段」不能当「结构字段」用**：`target` 在 PokéAPI 里本意是"这招瞄准谁"，
   但对「攻击后自己强化」的招它标的是对手 —— 我拿它当"能力变化的方向"用，于是 16 条招全反。
   正确做法是用**专门的分类字段**（`category = damage-raise/lower`）判方向。**教训**：跨数据源取值前先确认这个字段
   在源系统里的**真实语义**，别按名字想当然。
75. **「声称注入了」不等于「数据到了」**：注释写着"v17 把 hits 注入 MOVES"，但字段根本不存在，
   于是 19 条连击招静默失效了十几个版本 —— **不报错、不崩溃，只是少了个机制**。**教训**：
   机制类字段要在验收里**显式断言"数据存在"**，不能只测"代码有这个分支"。
76. **兜底逻辑会掩盖缺失**：属性兜底让"没实现的招"看起来有作用，于是没人发现挑衅变成降防御。
   改用"无效果就如实显示暂无"之后，58 条缺口一次暴露出来。**教训**：宁可显示"暂无"，也别用貌似合理的假数据填充 ——
   前者会推动补齐，后者会永久掩盖。
