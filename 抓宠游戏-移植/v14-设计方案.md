## 二、血量成长（← 需你拍板，见文末问题）

现状：`maxHp = base + lv * 1`，`base` 是手填的 34~46。
改造：`base` 由官方**种族值 HP** 换算，公式 `base = round(种族值 × k) + c`，`maxHp = base + lv × 1.4`。

| 方案 | 换算 | 5 级血量（妙蛙种子45 / 皮卡丘35 / 卡比兽160 / 幸福蛋255） | 50 级血量 |
|---|---|---|---|
| A（温和） | `round(种族值×0.28)+2` | 15 / 12 / 47 / 73 | 85 / 82 / 117 / 143 |
| B（明显） | `round(种族值×0.45)+3` | 23 / 19 / 75 / 118 | 93 / 89 / 145 / 188 |
| C（夸张） | `种族值×0.6+5` | 32 / 26 / 101 / 158 | 102 / 96 / 171 / 218 |

三方案其余规则相同：**升级时血量上限增长、当前血量同步增加等量**（就是你要的「升级涨血上限」）。
