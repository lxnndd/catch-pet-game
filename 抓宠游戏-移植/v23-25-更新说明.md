## v25：删掉全图路网，只留镇子里的街道（你最新提的）

**原来**：`genMap` 铺了 **中心广场 + 贯穿全图的十字大道 + 16 条辐射大道 + 8 条环路** —— 所以地图上到处是石板路，像一张蛛网（就是你截图里看到的）。

**现在**：**整段路网全部删除**，地图变成「自然地形 + 各座小镇」：
- 镇外：纯地区背景地形（草地/花田/岩地/沙地/雪地/水面），**一条路都没有**
- 镇内：各城镇自己铺十字街道（石板色）

**实测**：
```
城镇外的石板路 = 0 格（彻底清干净）
不在城镇范围内的 PATH 沙色地面：已还原为地区背景
```

**意外收获 —— 可达性反而大幅变好**（因为凿通逻辑改用地区背景地形，不再留沙路）：

| 地区 | 改之前（带水系宠可达） | **现在** |
|---|---|---|
| 矿洞 | 52% | **92%** |
| 平原 | 96% | 96% |
| 花海 | 79% | 79% |
| 荒漠 | 99% | 99% |

## v24：出生就在平原小镇（你报的"出生点一片荒漠、医院孤零零"）

两个原因，都修了：

1. **平原镇没建在出生点**：`findSpot` 按"离中心 85 格"选点，把平原镇选到了 **(202,104)**，离出生点 **52 格** → 医院当然孤零零。
   **修**：平原镇**固定建在出生点** (175,127)。实测**医院距出生点 6 格、道馆 7 格**，一出生就在镇中心。

2. **"荒漠"其实是道路**：中心广场 + 十字大道 + 16 条辐射大道**全用沙色 `PATH`**，在中心交汇成一大片沙地。
   **修**：道路骨架改**石板灰**。出生点周围 21×21 从「267 格沙色」变成「**草地 246 + 石板 90 + 树 44 + 花 14**」。

## v23：城镇地面与道馆触发（你报的三点）

| 问题 | 根因 | 修复 |
|---|---|---|
| **荒漠镇是绿地板** | 代码 `T[TOWN_GROUND[reg]] \|\| T.GRASS` —— **`T.PATH` 的值是 `0`（falsy）**，被 `\|\|` 顶成了草地 | 改成显式判 `!== undefined`；荒漠镇现在是 **PATH 131 格沙地** |
| **道馆提示后续不触发** | 我上一版做成了"只弹一次" | 按你要的改成**只有道馆正中心那一格才触发**（实测中心格=true，左/右/上一格=false） |
| **其他区域出现大道地板** | 城镇四向通道铺了**石板**、还向外延伸 **10 格** | 通道改铺**该地区自己的地面**、长度缩到 **4 格**；实测不属于任何城镇的石板 = **0 格** |
