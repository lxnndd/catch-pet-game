## 1. 伤害被削平 —— 根因是 85% 单次上限

你报的场景「52 级费洛美螂打 9 级懒人獭，100 威力飞踢只打 35 血」：**35 正好是懒人獭 9 级血上限 41 的 85%**。

`applyMove` 里有条老规则（v17 加的）：

```js
var capOf=Math.max(1, Math.round((atkIsSelf?B.emax:maxHpOf(selfP))*0.85));
if(dmg>capOf){ dmg=capOf; }
```

它本来是为了防止「属性克制叠加时一击秒杀、战斗没有来回」，但对**等级压制**的场景也一视同仁地削平了。

**改后**：上限只约束等级相近的对局，压制度够了就解除。

```js
var _tgtMax=(atkIsSelf?B.emax:maxHpOf(selfP));
var capOf=Math.max(1, Math.round(_tgtMax*0.85));
if(lvPress>=1.6) capOf=_tgtMax;      /* v29：等级压制明显 → 解除上限 */
```

`lvPress = clamp(0.5+0.5*(攻方等级/守方等级), 0.5, 2.0)`，阈值 1.6 约等于「攻方等级 ≥ 守方 2.2 倍」：

| 场景 | lvPress | 上限 |
|---|---|---|
| 52 级 → 9 级 | 2.00 | **解除（可一击带走）** |
| 50 级 → 20 级 | 1.75 | 解除 |
| 30 级 → 20 级 | 1.25 | 保留 85% |
| 同级对战 | 1.00 | 保留 85% |

实测：52 级费洛美螂对 9 级懒人獭，原始伤害 1920 → 上限解除为 41（= 对手满血）→ **一击带走**。

- **双方数量相同**：馆主出 `clamp(玩家队伍数, 1, 6)` 只 —— 你带 3 只，馆主也 3 只。

## 9. 城镇安全区 · 城镇间街道 · 左上角小地图（v29c）

- **小镇 = 安全区**：树围起来的那片（`|Δx|≤10, |Δy|≤8`）**不会遇到任何宠**。
  新增全局 `inTownAt(x,y)`，`move()` 里改成 `var _er = inTownAt(nx,ny) ? 0 : encRateOf(tv);`
  实测：城镇内随机走 **35230 步 → 遇敌 0 次**；对照组城镇外走 600 步 → 触发 42 次（说明是安全区生效，而不是遇敌率整体变低）。

- **城镇之间通十字街**：从平原镇（中心）向其余七镇各铺一条路。
  用 BFS 寻路，**优先绕开深水/浅水**，绕不开才穿水；沿途把树/岩/岩浆清成 `T.STREET`，但不压医院/道馆/联盟建筑。
  实测铺出 **772 格街道**，八个镇**全部可达**——队伍里不带水系宠也能一路走到海洋镇。

- **左上角小地图**：`#stage` 内新增 `#minimap`（264×188，CSS 显示 132×94，小屏 104×74）。
  地形缩略图**只渲染一次并缓存**（`_mmBase`，用 `map` 引用判断是否重建），每帧只叠画**小镇黄点**与**玩家当前位置红点**，所以不影响移动帧率。
  实测：49632 像素全部绘制、84 种颜色层次、`position:absolute; left:8px; top:8px`、8 个小镇标记齐全。
