## 二、野怪等级规则（你选的方案：地区区间 + 跟玩家浮动）

```
野怪等级 = clamp( 玩家最强宠等级 ± 3 , 该地区下限 , 该地区上限 )
新手保护：玩家 ≤2 级时，野怪不超过 3 级
```
实测（公网、真实开战）：
| 地区 | 玩家 Lv | 野怪实测 |
|---|---|---|
| 平原 1~25 | 1 | Lv1~3 |
| 花海 26~35 | 30 | Lv27~33 |
| 矿洞 36~45 | 40 | Lv37~42 |
| 荒漠 46~55 | 50 | Lv47~52 |
| 海洋 56~65 | 60 | Lv57~63 |
| 火山 66~75 | 70 | Lv68~73 |
| 雪原 66~75 | 70 | Lv69~73 |

**含义**：新手只会在平原碰到低等级；想拿高等级的宠就得往外走。低等级硬闯高地区会被区间下限顶住（风险自负，这是你选的方案）。

## 四、顺带修掉的问题（含你报的两个）

1. **「打的和抓的不是一个等级」** ← 你报的
   根因：`captureSuccess()` 里 `var pet=newPet(sp.id)` 没传等级，`newPet` 默认 **Lv.1**。
   已修：抓到手的宠**继承遇到的野怪等级**（实测：遇 Lv25 妙蛙种子 → 抓到也是 Lv25 ✅）。

2. **「对战 UI 显示不全」** ← 你报的
   根因：`.battle-stage{height:212px}` **写死高度**，而双方立绘各 120px + 名字 + 状态徽章 + 血条需要 ~210px/只，**两只叠放要 ~420px → 被 `overflow:hidden` 裁掉**（所以只看到敌方上半身、我方完全看不到）。
   已修：舞台改自适应高度 + 立绘/头像尺寸统一 + 新增窄屏紧凑规则。
   实测 5 种屏幕（360×640 / 390×844 / 430×932 / 820×1180 / 1280×800）**全部一屏放得下**、双方信息与立绘完整、4 技能 + 3 球 + 换宠 + 逃跑全在视口内。

3. **`#stage` 有两处冲突定义**（一处 1.6:1、一处 4/3）→ 统一为 1.6:1，与 216×156 的宽地图匹配。
4. **视野自适应**：原来 TILE 固定 32px，小手机上只看得到 10 格 → 改为按屏幕重算（TILE 34~44px）。
5. **训练师站位全部重排**：原来 10 位训练师的坐标是旧 72×52 地图的 → 按主题地区重新落位
   （矿工→矿洞、火山学者→火山、冲浪手→海洋、龙之使者→雪原、冠军→荒漠，其余在平原）。

## 六、已知取舍（如实说明）

1. **视野约 11×7 格**：地图大了 9 倍，一屏能看到的相对就小了（这是"地图真的变大"的必然结果）。想看得更远可以把 TILE 调到 28~30（格子更小、视野更宽），一句话就能改。
2. **矿洞可走率 51%、火山 62%**：岩壁/岩浆本身就是该地区的地形障碍（不是 bug）；如果你觉得太堵，我可以把岩壁覆盖率从 55% 降到 40%。
3. **林间/水畔**不再单独占一圈，而是**平原环内的地形特征**（树多=林间、水多=水畔），保持 1-25 级；玩家看到的地名与野怪池会跟着变。
4. **最外圈**三个地区（海洋/火山/雪原）在地图边缘相邻（1 格间距，已加海滩/沙地缓冲带）；反正它们是同级难度，不存在"误入高级区"。
5. **旧存档**：地图尺寸变了（`mapStr` 长度校验会失败），会自动重开地图，**宠物与等级保留**。
