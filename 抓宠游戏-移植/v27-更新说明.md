## 二、根因一：遇敌只判定「高草丛」和「水域」，雪原/火山等于永不遇敌

原代码 `move()` 里只有两条判定：

```js
if(!got && tv===T.TALL){  ...  Math.random()<0.20 ... }   // 高草丛 20%
if(!got && isWaterTile(tv)){ ... Math.random()<0.16 ... } // 水域 16%
```

而地图生成（`genMap`）给九地区铺的地面是这样的：

| 地区 | 地面配方（`抓宠游戏-v12-clean.html:896-901`） | 原可遇敌比例 |
|---|---|---|
| 平原 | 94% 普通草地 + 6% 高草 | 6% |
| 花海 | 76% 草地 + 14% 花田 + 10% 高草 | ~8.6% |
| 矿洞 | 81% 岩地 + 11% 高草 + 8% 岩壁 | 11% |
| 荒漠 | 88% 沙地(PATH) + 12% 高草 | 12% |
| 林间 | 大量树 + 少量草地 | 低 |
| **雪原** | **90% 雪地 + 10% 岩壁** | **0%** ❌ |
| **火山** | **74% 岩地 + 12% 岩浆 + 14% 岩壁** | **0%** ❌ |

普通草地、雪地、岩地、花田、沙地**全都不参与遇敌判定**。后果：

- **雪原、火山永远遇不到野生宠**；
- 平原 94% 是普通草地 → 走路基本不遇怪；
- 水域（海水/河水）反而 16% 一踩一个 → 海洋 8 步就撞一次，太频繁。

## 三、修复内容

### 1. 新增地形遇敌率表（`抓宠游戏-v12-clean.html:590-604`）

```js
var ENC_RATE={};
ENC_RATE[T.TALL]=0.20;        /* 高草丛 */
ENC_RATE[T.GRASS]=0.05;       /* 普通草地 */
ENC_RATE[T.FLOWER]=0.06;      /* 花田 */
ENC_RATE[T.SNOW]=0.10;        /* 雪原雪地 */
ENC_RATE[T.ROCKFLOOR]=0.08;   /* 矿洞/火山岩地 */
ENC_RATE[T.PATH]=0.05;        /* 荒漠沙地 */
ENC_RATE[T.WATER]=0.10;       /* 浅水 */
ENC_RATE[T.DEEP]=0.08;        /* 深海 */
function encRateOf(v){ return ENC_RATE[v]||0; }
```

**不在此表 → 永不遇敌**：树/岩壁/岩浆（本来就走不进去）、城镇地面/街道/道馆/医院/联盟会场。

### 2. `move()` 的遇敌判定改成查表

原来两条 `if`（TALL / 水域）合并为一次查表：

```js
var _er=encRateOf(tv);
if(!got && _er>0){
  maybeSpawnSparkle();
  if(Math.random()<_er){ draw(); openEncounter(rollEnemy()); return; }
}
```

闪光拾取（`got`）仍然优先于遇敌，行为不变。

## 五、遗留：稀有度仍未改（按你的选择）

「遇敌频率」修好了，但**抽到哪只宠的分布仍是老样子**，这个我没有动：

`抓宠游戏-v12-clean.html:1755-1761` 把 `RARITY_W=[1,0.087,0.0011]` 当作**每只宠的权重**累加，而池子里常见宠 498 只、稀有只有 28 只、神兽 87 只 —— 稀有的总概率被常见宠的数量稀释掉了。

20 万次模拟实测：

| 档位 | 设计目标 | 实际 |
|---|---|---|
| 常见 | 91.9% | **99.0 ~ 99.9%** |
| 稀有 | 8% | **0.1 ~ 0.96%** |
| 神兽 | 0.101% | **0.008 ~ 0.036%** |

也就是说：**现在照样几乎只能遇到常见宠**，稀有宠比设计值难遇 8~80 倍，神兽难 4~10 倍。

想修的话，改成「两级抽取」即可（先按档位概率抽常见/稀有/神兽，再在档内等概率取一只），档位概率与池子大小无关。随时可以做。
