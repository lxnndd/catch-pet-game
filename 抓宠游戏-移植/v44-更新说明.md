## 二、修复：联盟打完冠军后「结束不了」

### 根因

```js
// openLeague()：无论进度多少，按钮永远是「第 (LEAGUE_IDX+1) 位」
_pb.textContent = "⚔️ 挑战四天王（第 " + (LEAGUE_IDX+1) + " 位）";
_pb.onclick = function(){ beginLeagueBattle(LEAGUE_IDX); };
```

打完冠军后 `LEAGUE_IDX` 会涨到 **5**（= `REAL_E4.length`），于是：

- 按钮显示成「**第 6 位**」（你看到的「4/5 之后不对劲」就是这个）
- 点下去 `beginLeagueBattle(5)` → `REAL_E4[5]` 是 `undefined`
- 而函数里只有一句 `if(!who) return;` —— **静默返回，什么都不发生** = 「打完结束不了」

### 修复

| 场景 | 现在的表现 |
|---|---|
| 未集齐徽章 | 「知道了」按钮 + 提示去收集徽章 |
| 打到一半 | 按钮显示 **「⚔️ 挑战四天王（第 N 位 / 共 5 位）」**，文案写明「已击败 N / 5 位」 |
| 打到第 5 位 | 按钮变成 **「⚔️ 挑战冠军（青绿）」**，文案写「打赢他就通关！」 |
| **打完冠军** | 顶部标题区显示 **「徽章 8/8　🏆 已夺冠」**，文案「🏆 你已击败四天王与冠军，成为新的联盟冠军！」<br>按钮变成 **「🔁 重新挑战联盟」**（点了从四天王重打一轮） |
| 越界直调 | 给出提示「🏆 你已经打赢整个联盟了！」并自动重置（**不再静默失败**） |

另外**夺冠状态会写进存档**（`S.champion=1`）—— 以前刷新页面就丢，现在重开也显示「已夺冠」。

## 五、本批新增的坑

54. **「什么都没发生」也是一种 bug，而且最难查**：`beginLeagueBattle(5)` 因为 `if(!who) return;` 而静默返回 —— 没有报错、没有提示、界面也不变，玩家的描述只能是"结束不了"。**教训**：边界条件（索引越界、数组取空）不要只 `return`，要么给用户可见的反馈，要么把状态收敛回合法区间；验收脚本也要**显式断言"有反馈"**，而不只是断言"不报错"。
55. **进度变量涨过界后，UI 不能再用它直接算显示值**：`LEAGUE_IDX+1` 在通关后变成「第 6 位 / 共 5 位」这种自相矛盾的显示。**教训**：显示进度前先 `clamp` 或先判断「是否已完成」，别让"计数用变量"直接进 UI。
