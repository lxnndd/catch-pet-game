## 问题一：进化后血量基数不涨（48 处）——**最严重**

## 问题二：进化等级超出游戏等级节奏（2 处）

游戏里升级靠打野（经验 `10+等级×2`），训练师最高也就 50 级上下；下面这些要 60+ 级才能进化，实际玩不到。

| 进化 | 现要求等级 | 建议 |
|---|---|---|
| 双首暴龙 → 三首恶龙 | Lv64 | 压到 Lv50~55（和现有最高档对齐） |
| 小帕尔萨斯 → 帕尔萨斯 | Lv80 | 压到 Lv50~55（这条尤其离谱） |

## 问题三：进化前后属性完全没变（161 处，仅列出，通常可接受）

宝可梦原作里也有大量「属性不变、只涨种族值」的进化（如御三家二段），所以**不一定要改**——前提是血量基数得涨（见问题一）。

示例：妙蛙种子→妙蛙草、妙蛙草→妙蛙花、小火龙→火恐龙、杰尼龟→卡咪龟、卡咪龟→水箭龟、皮卡丘→雷丘、钻角犀兽→超甲狂犀、吉利蛋→幸福蛋、迷你龙→哈克龙、菊草叶→月桂叶、月桂叶→大竺葵、火球鼠→火岩鼠 等 161 处

## 问题四（新发现，优先级高）：5 个属性一个招式都没有 → 105 只宠学不到本系技能

招式表 99 个招式里，完全没有这 5 个属性的招：**超能力 / 幽灵 / 恶 / 钢 / 妖精**。
后果：这 5 系的宠只能用别的系的招，**属性克制对它们几乎不生效**（本系加成与克制优势拿不到）。

| 缺失属性 | 影响的宠 | 建议补的招（示例，可按你喜好换） |
|---|---|---|
| 超能力 | 28 只 | 念力(20威) / 精神强念(45威) / 意念头锤(40威) / 冥想(变化·强化) / 精神冲击(35威) |
| 幽灵 | 33 只 | 舌舔(15威) / 暗影球(40威) / 潜灵奇袭(45威) / 怨恨(变化·弱化) / 影子偷袭(先制20威) |
| 恶 | 103 只 | 咬碎(40威) / 恶之波动(45威) / 突袭(先制20威) / 挑衅(变化) / 诡计(变化·强化) |
| 钢 | 31 只 | 金属爪(25威) / 铁头(40威) / 加农光炮(45威) / 金属音(变化·弱化) / 子弹拳(先制15威) |
| 妖精 | 36 只 | 妖精之风(20威) / 魔法闪耀(45威) / 嬉闹(45威) / 撒娇(变化·弱化) / 月亮之力(45威) |

**建议改法**：每个缺失属性补 **5 个招**（2 个小威力 + 2 个大威力 + 1 个变化招），再给这 105 只宠按属性重新分配招式（保证至少 1 个本系招）。
补完后属性体系才真正完整——现在等于 18 属性里只有 13 个能打出本系伤害。

## 问题五：15 条进化链被主动跳过（目标形态不在数据源里）

这些在数据源（宝可梦/洛克/帕鲁三方）里查不到进化后的形态，为避免「进化到不存在的物种」，构建时主动没建链：

- 蹦蹦种子→蹦蹦草、贤隐武者→仁臻武君、踏云猴→火云神、猫老大→猫老爷、幻影霸主→幻影天主 等
- **建议**：要么给这些目标形态补一条数据（名字/属性/血量基数），要么明确「这几只就是最终形态」。

## 问题六：部分初阶宠血量基数偏低（27 只 < 45）

洛克档位最低是 50，宝可梦有 25~40 的初阶（如雪绒狐 33、毛掸儿 25）。这些宠 Lv1 血量约 22~23，属于正常偏脆，配合 v15 的开局伤害折算不会秒杀，**建议不改**。
