# 抓宠游戏 · Catch Pet Game

一款**单文件 HTML** 的宝可梦风格「抓宠 + 对战 + 道馆 + 联盟」网页游戏。
全部逻辑、样式、数据都内联在一个 `抓宠游戏-v12-clean.html` 里（约 1 MB），双击即可玩，无需构建、无需联网。

> 在线试玩：<http://47.105.123.182:8727/>

---

## 特性

### 内容规模
- **1205 只宠物**：宝可梦 1025 只 + 洛克王国 180 只（1100 普通 / 105 传说·幻之）
- **1093 个招式**：从 PokéAPI 抓取并按官方机制实现
- **18 个属性**：含完整克制表与官方属性配色
- **8 个道馆** + **联盟大会 128 强**（7 轮单败淘汰） + **四天王 + 冠军**

### 数值与规则（对标官方）
| 系统 | 实现 |
|---|---|
| 能力值 | 官方公式 `floor((2×种族+个体)×等级/100)+5`，个体值 IV=31 |
| 经验曲线 | 六种官方成长曲线（最快/快/中快/中慢/慢/最慢） |
| 经验分配 | 官方全队共享：参战 100%、其余存活队友各 50% |
| 伤害公式 | 官方主体 `floor(floor((2L/5+2)×威力×A/D)/50)+2` + 本系/克制/暴击/随机数 |
| 捕获 | 官方 `a=((3H−2C)×捕获率×球)/3H×状态` → 摇晃判定 |
| 能力等级 | ±6 级，`1±0.3n` 倍率，**保留到换场**（不逐回合衰减） |
| 出招顺序 | 先比先制度（官方 37 条）再比速度 |

### 已实现的招式机制
- **12 种附加状态**：畏缩、混乱、挑衅、定身法、寄生种子、束缚、扎根、恶梦、回复封锁、折磨、哈欠、灭亡之歌
- **场地系统**：光墙、反射壁、神秘守护、顺风、幸运咒语、撒菱、隐形岩、毒菱、黏黏网
- **特殊机制**：守住（完全免伤）、白雾、意念移物、**空中状态**（飞翔/弹跳/自由落体，仅 11 招可击中）、击落（解除空中 + 打断蓄力）、变身、反击/双面奉还/镜面反射、蓄力招、滚动/冰球（连续翻倍）、一击必杀、固定伤害、体重威力（重磅冲撞/踢倒）、连击
- **声音类招式**：35 条清单，地狱突刺（沉默）可封锁

### 玩法
- 探索 7 个地区（平原/花海/雪原/矿洞/火山/荒漠/海洋），野生宠物按地区等级段与进化阶段刷新
- 神兽野生个体一律 **70 级起**（约占刷新池 0.5%）
- 长按技能卡查看详细效果说明
- 技能池自由拖拽调整（支持「拖到空白 = 添加」）
- 队伍最多 6 只，共享经验

## 运行

### 方式一：直接打开（最快）
双击 `抓宠游戏-移植/抓宠游戏-v12-clean.html` 即可。

### 方式二：本地静态服务
```bash
cd 抓宠游戏-移植
node app/server.mjs
# 默认 http://127.0.0.1:8727/
# 可用环境变量覆盖：PORT、ROOT、LOG_DIR
```

`app/site/` 是部署用的站点目录（`index.html` 与游戏本体同内容，`avatars/` 存放 1285 张立绘）。

## 开发与验收

项目采用「脚本改 + 自动化验收」的流程：

```bash
# 数据生成（从 PokéAPI 缓存重建招式效果表）
node _work/tools/v57-gen-movefx.mjs --apply

# 验收（需要先起本地服务 + Edge headless，CDP 端口 9335）
node app/server.mjs &          # PORT=8728 ROOT=app/site
node _work/tools/v94-rarity-transform.mjs
```

每个版本都有对应的 `vNN-*.mjs` 验收脚本，覆盖伤害公式、捕获率、状态机制、刷新概率等。
