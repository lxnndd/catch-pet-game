## 玩法简介

游戏开局可以从九个世代的宝可梦御三家以及洛克王国初代三宠（共 30 只初始伙伴）里挑选一位一起出发。大世界按照关都到帕底亚的地理布局拼接成一张整图，走过海桥和山道就能直接跨区，点一下左上角的小地图可以放大全览当前地区的城镇和边界关口。

图鉴收录了 1,205 只可收服与培养的伙伴，战斗沿用原版 18 属性双属性倍率、25 种性格补正以及物攻/特攻分离伤害。晴雨沙雪天气、三大场地、替身、黑雾、同命、接棒、梦话、挥指以及各类固定伤害和体重威力招式都已接通，打不过的野生宠也能绕开或先去精灵中心免费回血整理队伍。进度的读写全部保存在本地浏览器里，下次打开点“继续冒险”就能接着走。

## 操作方式

- 移动：键盘 `WASD` 或方向键控制，也可以直接在地图画面上按住想要前进的方向奔跑；单按一次严格走一格。
- 地图：点击左上角小地图居中放大查看全局地标与出口方向，再点一次或按 `Esc` 收起。
- 招式详情：电脑端鼠标移到技能按钮上即可浮出招式说明与当前威力，手机端长按技能卡或右键也能查看；配招界面支持直接拖拽调整四格技能顺序。

## 本地运行

整个游戏的核心代码与图鉴数据都在单文件 `app/site/index.html` 中，不需要安装打包工具或配置编译环境。最简单的启动方式是在项目根目录运行自带静态服务：

```bash
node app/server.mjs
```

随后在浏览器打开 `http://127.0.0.1:8727/` 即可游玩（也可以直接双击打开 `app/site/index.html`）。

## 仓库结构

- `app/`：游戏前端页面、立绘与场景美术素材，以及零依赖静态服务器 `server.mjs`
- `data/`：整理后的精灵、招式、技能学习与进化链对照表
- `docs/`：[版本更新说明](docs/版本迭代说明.md)、[数据来源说明](docs/数据来源与总表说明.md)、[部署运维笔记](docs/部署与运维指南.md)与[踩坑记录](docs/Bug踩坑与经验记录.md)
- `tools/`：语法与数据校验脚本及服务端发布工具
