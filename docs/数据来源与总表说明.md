# 抓宠游戏 · 数据来源与总表说明

## 一、规模与数据来源

游戏共收录 **1,205 只宠物**（宝可梦 1,025 只 + 洛克王国 180 只；已彻底清除幻兽帕鲁）、**1,093 个招式**、**567 条进化链**，以及 **1,285 张 128×128 WebP 立绘**（外置在 `app/site/avatars/`）。

### 1. 宝可梦（1,025 只，图鉴 #1–1025 全量）

| 世代 | 数量 | 交叉查证来源 | 校验结果 |
|---|---|---|---|
| 关都 + 城都 #1–251 | 251 | PokéAPI + 52poke 世代招式表 | 种族值 247/247 一致；差异仅在译名 |
| 丰缘 + 神奥 #252–493 | 242 | PokéAPI + 52poke + pokemondb | 属性/种族值/招式表 242/242 全一致 |
| 合众 + 卡洛斯 #494–721 | 228 | PokéAPI + 52poke + pokemondb + Serebii | 3614/3620 行全一致；PP 差异用 Serebii 裁定 |
| 阿罗拉 + 伽勒尔 #722–905 | 184 | 同上四源 | PP 世代差异 65 处逐条裁定 |
| 帕底亚 + 传说 #906–1025 | 202 | 上述 + pokemon.cn 大陆官方图鉴 | 译名统一采用大陆官方简中 |

### 2. 洛克王国（180 只，已剔除拟人形）
- **来源**：dvg 资料站（`roco.dvg.cn`）+ 百度百科双向校验，六维之和与资料站总和 520/520 完全一致；立绘按 `kz-{编号}` 直接对应官方图源，确保 180/180 零错位。

### 3. 已知数据缺口（如实记录，未编造）
1. 洛克王国 21 处超进化形态不在原资料站内，对应进化链在常规终点处截断。
2. 洛克王国技能原无官方学习等级，按技能表顺序与威力分段推定分配到 `p0~p65`。
3. 宝可梦与洛克存在 4 只同名宠物（独角虫、超音蝠、地鼠、喵喵），分属不同世界各自保留。
4. 招式跨世代数值冲突（56 处）统一取「威力最大」，记录在 `data/move-conflicts.json`。
5. 宝可梦招式无官方结构化效果时**不编造属性兜底**，仅洛克缺失效果的变化技保留按属性兜底。

## 二、`data/` 目录文件索引

| 文件 | 用途 |
|---|---|
| `species-v17.json` / `moves-v17.json` / `evo-v17.json` | 构建单文件游戏核心数据的结构化 JSON（物种、招式、进化链） |
| `move-fx.json` / `move-desc.json` / `move-flavor-en.json` | 招式附加效果表（`MOVE_FX`）、中文描述与英文风味文本 |
| `pokeapi-move-map.json` / `sv-learnsets.json` / `pokemon-meta.json` | PokéAPI 招式映射、第九世代（朱/紫）升级技能表、基础经验与成长曲线元数据 |
| `move-conflicts.json` | 56 处跨世代招式数值冲突裁定记录 |
| `poke-kanto-johto.mjs` | 关都 + 城都（#1–251）双源核对原始数据模块 |
| `宠物总表.csv` / `.md` | 1205 只宠物的属性、分布、来源汇总表 |
| `招式总表.csv` | 1093 个招式的属性、威力、PP、命中明细表 |
| `技能学习表.csv` / `.md` | 7 个学习池（`p0` / `p15` / `p25` / `p35` / `p45` / `p55` / `p65`）明细与分布统计 |
| `进化链表.csv` / `.md` | 进化链条、等级与分支明细 |
