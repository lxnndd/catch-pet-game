## 二、历史踩坑全集（#1–#90，按领域分类）

### A. 战斗公式、数值与状态机制
1. **乘除方向写反会静默反转机制（#44）**：`defT.def * dstag` 原先写在分子而非分母，导致「对手防御越高打得越疼」，因裸装无 buff 测试长期未暴露。
2. **同一量在两层各乘一次（#65）**：v47 将 `A/D` 放进 `_core` 时，`atkM` 中仍留有一份 `statMul`，等效 `(A/D)²`（与 `lvPress` 平方同源）；改公式必须全文搜所有出现点。
3. **85% 单次伤害上限会掩盖上游 Bug 与 Buff 效果（#19, #27, #66, #76）**：同级倍率畸高或攻击 +1 均被 85% 削平，日志看不出异常；极端等级压制、固定伤害、一击必杀必须显式豁免。
4. **同名函数覆盖与公式块误删（#31, #37, #43）**：曾新增 `spdOf(sp,lv)` 覆盖原速度 `spdOf(p)`；大段替换公式曾误删紧邻的 `statOf()`，且静态语法检查无法发现，必须靠浏览器实测 + `catch-pet-dupcheck.mjs`。
5. **战斗真值字段不一致（#13, #14, #70, #87）**：敌方真血量是 `B.ehp` 而非 `B.foe.hp`；敌方选招必须读 `B.ePP` 的键而非物种表；复制招式后必须同步重建 `pet.pp` 的键映射。
6. **同一回合敌方行动被触发两次（#68）**：敌先手 `enemyStrike` 后，玩家出招必须带 `noFoeTurn=true` 阻止再调 `enemyTurnSoon`。
7. **概率/条件双算与自创机制（#77, #78）**：一击必杀不能在命中阶段与 `ohko` 阶段各判一次 30%；注释写「某式」往往意味着自创机制（如曾经的每回合 buff 衰减），对标官方时应清除。
8. **特殊招判定不能用 `!mv.power`（#75）**：威力为 0 的攻击招（地球上投、蛮干、一击必杀）会被误推入变化技分支，必须按 `mv.cat === "变化"` 判定。

### B. 技能系统、进化与野生池
9. **进化等级与阶段区间自洽（#24, #25, #67）**：外部数据非等级进化 `lv=0` 会导致 1 级就进化；不能用 `!s.ev` 过滤野生池（会把基础御三家全挡掉），应改用 `isEvolvedForm()`；阶段区间与目标区间无交集时必须返回 `null` 过滤掉，不能退回默认区间（否则出现 Lv9 掘地兔）。
10. **补全函数与反向操作冲突（#41）**：`ensureMoves()` 自动补满 4 招吃掉了「拖回左边卸下技能」的操作；现在仅在技能数为 0 时兜底补 1 招。
11. **同操作双入口行为不一致（#83）**：点击换招支持「未满直接加」，拖拽落点只认卡片不认容器空白，导致玩家反馈「拖不过来」。
12. **善意「进化补满血」与遍历变异（#63, #64）**：`runEvoCheck()` 给倒下宠满血复活 + `gainExp` 边遍历边进化改写 hp，破坏全队共享经验名单；需维持倒下状态且遍历前先快照名单。
13. **经验曲线与给经验须成对修改（#38, #39, #40）**：分段经验公式需特判 1 级累计为 0，且各能力项必须统一官方量级。
14. **难度基准对象（#69）**：新手期野怪跟随应取当前出战宠 `wildBaseLv()`，而非队伍最高 `topPartyLv()`。

### C. 第三方数据源与脚本管道陷阱
15. **官方数据缺失 ≠ 无效果（#46, #71, #80）**：PokéAPI 无 `sound` flag 需手工建表；`unique` / `field-effect` 类招式 `stat_changes` 为空并非无效果；但确实无效果的招不能用属性瞎编兜底。
16. **字段语义与增量译名陷阱（#18, #32, #33, #35, #47, #72, #73, #81, #82）**：
    - `damage-raise` 类招式的 PokéAPI `target` 标成对手，需看 `meta.category`；
    - 物种编号取 `id` 而非布尔标志 `pk`；
    - 过滤 PokéAPI 68 条「无法使用这个招式…建议忘记」废文案；
    - 改过脚本参数（如洛克六维缩放 `const K`）必须实际跑 `--apply` 并核查产物；
    - 数据改译名时生成器需配别名表，按 id 编号取图最稳妥（批量下载需支持覆盖历史错图 #17）。
17. **跨段注入与静默失败（#10, #74, #84）**：绝不用 `indexOf(A) ~ indexOf(B)` 跨段替换（会吞掉中间函数）；生成器需自带回读校验与顶层边界锚定；改动后必跑 `catch-pet-syntax.mjs` 与 `catch-pet-dupcheck.mjs`。

### D. 界面、交互与工程环境
18. **UI 细节与冗余清理（#28, #29, #34, #51, #54, #55, #56, #60）**：数值读取走统一兜底函数（`ppMaxOf`）；浅色属性标签（电/冰/地面/钢/虫）用深色文字；进度显示先 `clamp` 防越界；文案分子分母保持同集合口径；删功能同步清渲染与入口；CSS flex 标签加 `white-space:nowrap; flex:0 0 auto`。
19. **地图与地形事件联动（#21, #22）**：新地形必须同步进 `ENC_RATE` 表，否则整片区域永不遇敌。
20. **运维与脚本环境（#3–#8, #30, #88–#90）**：
    - CDP 验收必开 `Network.setCacheDisabled` + URL 时间戳，清 `localStorage` 跑干净起点，随机特性/伤害需固定值；
    - 模板字符串注入 JS 正则注意双反斜杠转义（#53）；
    - PowerShell 不支持 bash here-string（`<<<`），多行脚本与提交信息写文件执行；
    - systemd unit 须 base64 传输且 `Description` 用纯 ASCII；阿里云轻量防火墙需放行 8727 端口；
    - 临时打包文件避免落在受限 `%TEMP%` 或含中文路径的命令行参数里。
